# Polymarket Skills

The ultimate directory of MCP servers and tools for real-time prediction market data and trading automation.

## Skills

### Polymarket Market Intelligence
Access real-time Polymarket market data including markets, odds, prices, and more.

### User Trading Insights
Access user trading history, portfolio analytics, P&L analysis, and leaderboard rankings.

### Polymarket Trading (Coming Soon)
Execute trades, manage orders, and interact with the Polymarket CLOB.
